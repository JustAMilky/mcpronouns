# mcpronouns
A KubeJS script that allows Minecraft server members to display their pronouns easily.

## Commands
```
pronouns set <pronouns>
```
Sets the executor's pronoun display to the input value,

```
pronouns clear
```
Clears the executor's pronoun display,

## Installation
Put mcpronouns.js in `kubejs/server_scripts/` or clone this repo there.

## Updating
If you cloned this repo into `kubejs/server_scripts/` then just run `git pull`. If you installed manually, just replace mcpronouns.js.
